# WarehousePathing

A project for determining optimal routes in a warehouse using genetic algorithms.

## Install

**dotnet 10 REQUIRED**

```bash
git clone https://github.com/KaNiuSii/WarehousePathing.git

cd WarehousePathing
```

## Run

```bash
dotnet run --project .\Visualizer\Visualizer.csproj
```
